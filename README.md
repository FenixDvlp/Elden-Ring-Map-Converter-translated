# Elden-Ring-Map-Converter-translated
English translation of modding tool for Elden ring Nightreign .

Original tool : https://github.com/xtq626/Elden-Ring-Map-Converter/tree/main .

Original Author : xtq626 .

## Known issues

Some UI text is still in Chinese (on 1 page). It does not affect how the tool works.

**"Merge map collision" tab, buttons:**
- 选文件... = Browse... (choose an input file)
- 另存为... = Save as... (choose where to save the output)

**"Merge map collision" tab, File picker dialogs (file type filters):**
- 碰撞档案头 (*.hkxbhd) = Collision archive header (*.hkxbhd)
- 所有文件 (*.*) = All files (*.*)
